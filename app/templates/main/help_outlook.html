Outlook novo (New Outlook para Windows)

  1. Abra o Outlook e clique no ícone de Configurações (engrenagem).
  2. Vá em Contas > Assinaturas.
  3. Se houver mais de uma conta, selecione a conta para a qual deseja aplicar a assinatura.
  4. Clique em Adicionar assinatura e dê um nome a ela.
  5. Clique dentro da caixa de edição, no local onde a imagem deve aparecer, e use o botão de inserir imagem da barra de ferramentas para selecionar o arquivo da sua assinatura.
  6. Marque as caixas para aplicar a assinatura em novas mensagens e/ou respostas, se desejar.
  7. Clique em Salvar.

Outlook clássico (Outlook para Windows – versão desktop tradicional)

  1. Abra uma nova mensagem de e-mail.
  2. Na guia Mensagem, clique em Assinatura > Assinaturas...
  3. Em "Selecionar assinatura para editar", clique em Novo (ou selecione uma existente).
  4. Na caixa de edição, posicione o cursor onde a imagem deve aparecer e clique no ícone de Imagem.
  5. Selecione o arquivo PNG/JPG gerado pelo sistema e clique em Inserir.
  6. Se necessário, clique com o botão direito na imagem, escolha Imagem, ajuste o tamanho na aba Tamanho mantendo Bloquear proporções marcado.
  7. Clique em OK e depois em OK novamente para salvar a assinatura.

Outlook na Web (Outlook.com / Office 365)

  1. Acesse Configurações > Contas > Assinaturas.
  2. Clique dentro da caixa de assinatura, no local desejado.
  3. Use a opção de inserir imagem para adicionar o arquivo gerado.
  4. Salve as alterações.

Dicas importantes

  • Os formatos aceitos pelo Outlook são JPG, PNG e GIF — os formatos gerados por este sistema (PNG e JPG) são totalmente compatíveis.
  • Prefira o formato PNG quando possível: mantém o texto nítido, sem os artefatos de compressão do JPG.
  • Este sistema já gera a imagem em uma resolução adequada para assinaturas (nítida em telas comuns e retina, sem deixar o arquivo pesado).
  • Depois de inserir a imagem, evite redimensioná-la manualmente de forma desproporcional — isso pode distorcer o texto.
